# iclx apt repository

Signed apt repository for **CableBox**, a retro cable-box TV shell for Tvheadend, served at
**https://apt.icecubelabs.xyz/**. It has packages for `amd64`, `arm64` (Raspberry Pi 4/5) and `riscv64` (RISC-V boards).

This repo is generated by reprepro and published with GitHub Pages. Don't edit files here by hand.

## Requirements

Debian 13 (trixie) or **trixie-based** Raspberry Pi OS. Bookworm-based images are not supported
(the packages need glibc 2.39 or newer).

## Setup

**1. Install the signing key**

```sh
sudo curl -fsSLo /usr/share/keyrings/cablebox.gpg https://apt.icecubelabs.xyz/cablebox.gpg
gpg --show-keys /usr/share/keyrings/cablebox.gpg
```

The fingerprint must be `F46D BCC4 C6F9 98CC AD48  55B8 07F1 F103 2119 CCCD`. If this step fails,
`apt update` will later report *"Failed to parse keyring /usr/share/keyrings/cablebox.gpg … is not signed"*.

**2. Add the repository**

```sh
printf 'Types: deb\nURIs: https://apt.icecubelabs.xyz/\nSuites: trixie\nComponents: main\nSigned-By: /usr/share/keyrings/cablebox.gpg\nArchitectures: amd64 arm64 riscv64\n' \
  | sudo tee /etc/apt/sources.list.d/cablebox.sources
```

**3. Install CableBox**

```sh
sudo apt update
sudo apt install cablebox
```

**4. Start it**

Installing doesn't start anything. To make the box boot into the TV interface (it takes over the
console on tty1) and enable HDMI-CEC remote control:

```sh
sudo systemctl enable --now cablebox cablebox-cec
```

The first start shows a setup screen for your Tvheadend server (for example
`http://192.168.1.10:9981`, using Digest login).

## Updates

New versions published here appear in CableBox's on-screen "System Update Available" prompt.
You can also update with `sudo apt upgrade`.

## Troubleshooting

- **`apt update` says the repository "is not signed" or shows `NO_PUBKEY`:** the signing key was
  updated and this machine still has the old key file. Run step 1 again, then `sudo apt update`.
  CableBox 0.1.1 and later keep the key file up to date automatically.
- **"Release file … is expired":** the repository wasn't re-signed in time. Wait and retry;
  it's re-signed weekly.
