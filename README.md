# ICLX apt repository

Signed Debian packages from **Ice Cube Labs**, served at **https://apt.icecubelabs.xyz/**.
It covers `amd64`, `arm64` and `riscv64`.

This repo is generated by reprepro and published with GitHub Pages. Don't edit files here by hand.

## Requirements

Debian 13 (trixie) or a **trixie-based** Raspberry Pi OS. Bookworm-based systems are not supported.

## Setup

**1. Install the signing key**

```sh
sudo apt install curl        # if it isn't installed yet
sudo curl -fsSLo /usr/share/keyrings/iclx-archive-keyring.gpg https://apt.icecubelabs.xyz/iclx-archive-keyring.gpg
gpg --show-keys /usr/share/keyrings/iclx-archive-keyring.gpg
```

The primary key fingerprint must be `F46D BCC4 C6F9 98CC AD48  55B8 07F1 F103 2119 CCCD`.

**2. Add the repository**

```sh
printf 'Types: deb\nURIs: https://apt.icecubelabs.xyz/\nSuites: trixie\nComponents: main\nSigned-By: /usr/share/keyrings/iclx-archive-keyring.gpg\nArchitectures: amd64 arm64 riscv64\n' \
  | sudo tee /etc/apt/sources.list.d/iclx.sources
```

**3. Keep the key up to date**

```sh
sudo apt update
sudo apt install iclx-archive-keyring
```

This package keeps the key file current when the signing key changes. Every ICLX package also
depends on it.

## Troubleshooting

- **"Repository … changed its 'Origin' value from 'CableBox' to 'ICLX'"** (machines set up before
  the rename): accept it once with `sudo apt update --allow-releaseinfo-change`.
- **The repository "is not signed" or shows `NO_PUBKEY`:** this machine has an old copy of the
  key. Run step 1 again, then step 3 so it stays current.
- **"Release file … is expired":** the repository wasn't re-signed in time. Wait and retry; it's
  re-signed weekly.
- **"Conflicting values set for option Signed-By"**: this machine has both the old
  `cablebox.sources` and the new `iclx.sources`. Remove the old one:
  `sudo rm /etc/apt/sources.list.d/cablebox.sources`, then run `sudo apt update --allow-releaseinfo-change`.
- Set up with the older `cablebox.sources` instructions and don't want to switch? It keeps working
  as it is (don't add `iclx.sources` too); `iclx-archive-keyring` maintains
  `/usr/share/keyrings/cablebox.gpg`.
