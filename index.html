iclx apt repository

Signed apt repository for CableBox, a retro cable-box TV shell for Tvheadend. Packages are built for amd64 and arm64 (Raspberry Pi 4/5).

Requirements

Debian 13 (trixie) or trixie-based Raspberry Pi OS. Bookworm-based images are not supported (the packages need glibc 2.39 or newer).

1. Install the signing key

sudo curl -fsSLo /usr/share/keyrings/cablebox.gpg https://apt.icecubelabs.xyz/cablebox.gpg

Check it before continuing. The fingerprint must be F46D BCC4 C6F9 98CC AD48 55B8 07F1 F103 2119 CCCD:

gpg --show-keys /usr/share/keyrings/cablebox.gpg

If this step fails, apt update will later report “Failed to parse keyring /usr/share/keyrings/cablebox.gpg … is not signed”.

2. Add the repository

printf 'Types: deb\nURIs: https://apt.icecubelabs.xyz/\nSuites: trixie\nComponents: main\nSigned-By: /usr/share/keyrings/cablebox.gpg\n' \
  | sudo tee /etc/apt/sources.list.d/cablebox.sources

3. Install CableBox

sudo apt update
sudo apt install cablebox

4. Start it

Installing doesn't start anything. To make the box boot into the TV interface (it takes over the console on tty1) and enable HDMI-CEC remote control:

sudo systemctl enable --now cablebox cablebox-cec

The first start shows a setup screen for your Tvheadend server (for example http://192.168.1.10:9981, using Digest login).

Updates

New versions published here appear in CableBox's on-screen “System Update Available” prompt. You can also update with sudo apt upgrade.
