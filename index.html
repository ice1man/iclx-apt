ICLX apt repository

Signed Debian packages from Ice Cube Labs for amd64, arm64 and riscv64.

Requirements

Debian 13 (trixie) or a trixie-based Raspberry Pi OS. Bookworm-based systems are not supported.

1. Install the signing key

sudo apt install curl        # if it isn't installed yet
sudo curl -fsSLo /usr/share/keyrings/iclx-archive-keyring.gpg https://apt.icecubelabs.xyz/iclx-archive-keyring.gpg
gpg --show-keys /usr/share/keyrings/iclx-archive-keyring.gpg

The primary key fingerprint must be F46D BCC4 C6F9 98CC AD48 55B8 07F1 F103 2119 CCCD.

2. Add the repository

printf 'Types: deb\nURIs: https://apt.icecubelabs.xyz/\nSuites: trixie\nComponents: main\nSigned-By: /usr/share/keyrings/iclx-archive-keyring.gpg\nArchitectures: amd64 arm64 riscv64\n' \
  | sudo tee /etc/apt/sources.list.d/iclx.sources

3. Keep the key up to date

sudo apt update
sudo apt install iclx-archive-keyring

This package replaces the key file from step 1 and keeps it current when the signing key changes. Every ICLX package also depends on it.

Troubleshooting

“Repository … changed its 'Origin' value from 'CableBox' to 'ICLX'” (machines set up before the rename): accept the change once:

sudo apt update --allow-releaseinfo-change

The repository “is not signed” or NO_PUBKEY: this machine has an old copy of the signing key. Run step 1 again, then step 3 so it stays current.

“Release file … is expired”: the repository wasn't re-signed in time. Wait and retry; it's re-signed weekly.

“Conflicting values set for option Signed-By”: this machine has both the old cablebox.sources and the new iclx.sources. Remove the old one:

sudo rm /etc/apt/sources.list.d/cablebox.sources
sudo apt update --allow-releaseinfo-change

Set up with the older cablebox.sources instructions and don't want to switch? It keeps working as it is (don't add iclx.sources too). iclx-archive-keyring maintains /usr/share/keyrings/cablebox.gpg.
